# Монетизация ArmFinCredit

Кредитный калькулятор хорошо монетизируется: пользователь находится **в момент принятия финансового решения**. Это самый дорогой трафик в рекламе. Ниже пять источников дохода, отсортированных по потенциалу. Все они уже встроены в код.

| # | Источник | Где в коде | Что нужно сделать вам |
|---|----------|------------|------------------------|
| 1 | **Партнёрские предложения банков (CPA/CPL)** | `/offers`, `src/config/monetization.js` → `PARTNER_OFFERS` | Договориться с банками/МФО/маркетплейсами, вставить реальные ссылки |
| 2 | **Google AdSense** | `src/components/AdSlot.jsx`, 6 рекламных блоков | Создать рекламные блоки в AdSense и вставить их ID в env |
| 3 | **Pro-подписка** ($1.99/мес или $9.99 навсегда, 7 дней бесплатно) | `/pro`, `src/context/ProContext.jsx`, `api/license.js` | Создать продукт в Lemon Squeezy или Gumroad, вставить ссылки на оплату |
| 4 | **Прямая продажа рекламы банкам** | блок «Стать партнёром» на `/offers` | Отвечать на письма `partners@…` |
| 5 | **ИИ-советник** (крючок для Pro) | `api/ai.js`, `src/components/AiAdvisor.jsx` | Получить бесплатный ключ Gemini |

---

## 1. Партнёрские предложения: главный источник дохода

Одна одобренная заявка на кредит приносит банку сотни долларов. Поэтому банки и кредитные маркетплейсы платят за лид или выдачу. Страница `/offers` берёт расчёт пользователя и показывает:
- ориентировочный платёж у партнёра;
- **сколько он сэкономит** по сравнению со своим расчётом (это мотивирует нажать «Оформить»);
- подходит ли предложение по сумме и сроку.

Сейчас там 3 демо-карточки с пометкой «Пример». Кнопки в них не кликаются. Чтобы включить реальное предложение:

```js
// src/config/monetization.js
{ id: 'mybank', name: 'Название банка', rateFrom: 11.9, maxAmount: 20000000, maxTerm: 60,
  kind: {...}, perks: {...}, url: 'https://партнер/ссылка?ref=XXX', demo: false }
```

UTM-метки (`utm_source=armfincredit`) добавляются автоматически. Раскрытие информации о вознаграждении уже есть на странице и в Политике конфиденциальности.

## 2. AdSense

- `ads.txt` лежит в `public/`. Без него AdSense урезает доход.
- Скрипт рекламы **загружается только для бесплатных пользователей**. У Pro рекламы действительно нет, и сайт работает быстрее.
- Под каждым рекламным блоком есть ссылка «Убрать рекламу →», которая ведёт на `/pro`. Реклама сама продаёт подписку.
- Пока ID блоков пустые, работает только Auto ads (если он включён в кабинете AdSense).

**Что сделать:** AdSense → Реклама → По рекламным блокам → «Медийная реклама». Создайте 6 блоков и вставьте их ID в Vercel env: `VITE_AD_SLOT_CALCULATOR`, `…_SCHEDULE`, `…_EARLY`, `…_OFFERS`, `…_SAVED`, `…_LANDING` (посадочные SEO-страницы).

Для посетителей из ЕС включите в AdSense раздел «Конфиденциальность и сообщения» → GDPR (готовый баннер согласия от Google, код не нужен).

## 3. Pro: минимальная цена и пробный период

| | Free | Pro |
|---|---|---|
| Калькулятор, график, досрочка | ✅ | ✅ |
| ИИ-советник | 3 вопроса/день | 100/день |
| Сохранённые расчёты | 3 | 50 |
| Сравнение кредитов | 2 | 4 |
| PDF | с водяным знаком | чистый |
| Экспорт CSV | — | ✅ |
| Реклама | есть | нет |

**Пробный период:** 7 дней, без карты, запускается одной кнопкой. Paywall всплывает в момент, когда пользователь упирается в лимит (4-е сохранение, CSV, 3-й кредит в сравнении, закончились вопросы к ИИ). Это самая эффективная точка для продажи.

**Как подключить оплату** (Stripe не принимает продавцов из Армении, поэтому используем merchant-of-record сервисы, которые сами платят НДС):

1. **Lemon Squeezy** (рекомендую): создайте 2 продукта (Monthly-подписка и Lifetime) с включённой опцией **License keys**.
   - Checkout-ссылки → `VITE_CHECKOUT_URL_MONTHLY`, `VITE_CHECKOUT_URL_LIFETIME`
   - `LEMONSQUEEZY_STORE_ID` = ID вашего магазина
2. Или **Gumroad**: `LICENSE_PROVIDER=gumroad`, `GUMROAD_PRODUCT_ID=…`

Покупатель получает ключ на e-mail и вводит его на `/pro`. Сервер проверяет ключ (`api/license.js`) и раз в 3 дня перепроверяет его, так что после возврата денег или окончания подписки Pro отключается.

`PRO_DEMO_KEYS=KEY1,KEY2` — ключи, которые всегда открывают Pro. Подходят для тестов, розыгрышей и блогеров.

> Пока ссылки на оплату не заданы, кнопки показывают «Скоро», а пробный период работает.

## 4. Бесплатный ИИ

`api/ai.js` работает с любым OpenAI-совместимым провайдером. Ключ хранится только на сервере.

- **Google Gemini (по умолчанию):** бесплатный ключ на https://aistudio.google.com/apikey → `AI_API_KEY`
- Groq (бесплатно, очень быстро): `AI_BASE_URL=https://api.groq.com/openai/v1`, `AI_MODEL=llama-3.3-70b-versatile`
- OpenRouter: любая модель с суффиксом `:free`

ИИ видит текущий расчёт пользователя (сумму, ставку, срок, платёж, APR) и отвечает на его языке (AM/RU/EN).

**Проверка:** откройте в браузере `https://armfincredit-app.vercel.app/api/ai`. Страница покажет, задан ли ключ (`configured`), какая модель ответила (`model`) и, если что-то не так, точную ошибку провайдера (`detail`), например «API key not valid». Если `configured: false` — ключ не попал в этот деплой: проверьте имя переменной и окружение Production, затем сделайте Redeploy.

Если ответ пришёл с пометкой «Офлайн-анализ», наведите на неё курсор — появится причина. Та же причина пишется в консоль браузера (F12).

Если `AI_MODEL` не задан, сервер по очереди пробует `gemini-flash-latest`, `gemini-2.5-flash`, `gemini-2.0-flash`. Поэтому ИИ не сломается, когда Google отключит старую модель.

**Если ключа нет или бесплатная квота провайдера закончилась,** советник не ломается: он отвечает встроенным офлайн-анализом (`src/lib/insights.js`) с реальными цифрами (экономия от досрочки, аннуитет или дифференцированный платёж, цена 1 п.п. ставки).

## 5. SEO: бесплатный трафик из Google и Яндекса

Сайт собирается в браузере, поэтому раньше поисковики видели почти пустую страницу. Теперь при сборке (`npm run build`) каждая страница сохраняется как **готовый HTML** со своим заголовком, описанием, `canonical` и `hreflang`. Код: `scripts/prerender.js`, `src/entry-server.jsx`.

- **Посадочные страницы под поисковые запросы.** 4 темы × 3 языка = 12 страниц с отдельными адресами, текстом, советами и FAQ (разметка `FAQPage`):

  | Тема | 🇦🇲 | 🇷🇺 | 🇬🇧 |
  |---|---|---|---|
  | Ипотека | `/hy/hipotekayin-hashvich` | `/ru/ipotechnyj-kalkulyator` | `/en/mortgage-calculator` |
  | Автокредит | `/hy/avtovarki-hashvich` | `/ru/avtokredit-kalkulyator` | `/en/car-loan-calculator` |
  | Потребкредит | `/hy/sparoghakan-varki-hashvich` | `/ru/potrebitelskij-kredit-kalkulyator` | `/en/personal-loan-calculator` |
  | Досрочное погашение | `/hy/vaghajamket-marman-hashvich` | `/ru/dosrochnoe-pogashenie-kalkulyator` | `/en/early-repayment-calculator` |

- **Главная на каждом языке:** `/hy`, `/ru`, `/en`.
- `sitemap.xml` генерируется автоматически при сборке, со всеми языковыми версиями.
- Тексты страниц лежат в `src/seo/landings.js`, заголовки остальных страниц — в `src/seo/meta.js`. Новая тема = новый объект в `LANDINGS`: страница, ссылки и sitemap появятся сами.

**Что сделать:**
1. Добавьте сайт в **Google Search Console** (https://search.google.com/search-console) и отправьте `https://armfincredit-app.vercel.app/sitemap.xml`.
2. Добавьте сайт в **Яндекс Вебмастер** (https://webmaster.yandex.ru) и отправьте туда тот же sitemap — там русскоязычная аудитория.
3. Когда появится свой домен, укажите его в переменной `VITE_SITE_URL` и сделайте Redeploy.

## 6. Встраиваемый виджет калькулятора (`/widget`)

Любой сайт (автосалон, застройщик, агентство недвижимости, блог) вставляет калькулятор одной строкой:

```html
<div data-armfincredit data-lang="ru" data-amount="8000000" data-rate="13" data-term="60" data-accent="e11d48" data-ref="dealer-1"></div>
<script src="https://armfincredit-app.vercel.app/embed.js" async></script>
```

На странице `/widget` владелец сайта выбирает язык, тему, цвет и параметры и копирует готовый код.

**Как виджет приносит деньги:**
- **Бесплатная версия** содержит ссылку «Калькулятор от ArmFinCredit». Это обратные ссылки для SEO и новые посетители.
- Кнопки **«Полный график»** и **«Найти ставку ниже»** ведут на ваш сайт — на рекламу, Pro и партнёрские предложения. В ссылках есть метка `utm_source=<ref>`, поэтому в аналитике видно, какой сайт приводит посетителей.
- **White-label** — платная версия для бизнеса: без вашего логотипа и с кнопкой партнёра «Подать заявку». Блок на `/widget` ведёт на `partners@…`. Цену назначаете вы, например от $20–50 в месяц за сайт.

Технически: `public/embed.js` вставляет iframe на `/embed`. Высота подстраивается автоматически, рекламы и ИИ внутри виджета нет. Остальные страницы защищены от встраивания заголовком `X-Frame-Options`.

## Настройка Vercel (5 минут)

Vercel → Project → Settings → Environment Variables. Полный список в `.env.example`. Минимум для старта:

```
AI_API_KEY=...                     # бесплатный Gemini
VITE_AD_SLOT_CALCULATOR=...        # из AdSense
VITE_CHECKOUT_URL_LIFETIME=...     # из Lemon Squeezy
LEMONSQUEEZY_STORE_ID=...
```

Для локальной разработки скопируйте `.env.example` в `.env.local`. `npm run dev` поднимает и фронтенд, и `/api/*`.
